# 🚗 Ride Flow Analysis – Power BI Dashboard

## 📊 Project Overview

**Ride Flow Analysis** is an interactive Power BI dashboard developed to analyze online ride-booking data.

The dashboard provides insights into bookings, revenue, cancellations, vehicle types, customer ratings, payment methods, ride distance, customer retention, and service quality.

## 🛠️ Tools & Technologies

* Power BI
* Power Query
* DAX
* Excel / CSV
* Data Cleaning
* Data Visualization

## 📌 Key Analysis

### 1. Booking Analysis

* Total bookings
* Monthly booking trends
* Booking status
* Successful and cancelled rides

### 2. Revenue Analysis

* Total booking value
* Revenue per kilometer
* Revenue by vehicle type
* Revenue by payment method
* Revenue by day part
* Revenue tiers

### 3. Cancellation Analysis

* Customer cancellation reasons
* Driver cancellation reasons
* Cancellation percentage
* Completed vs cancelled rides

### 4. Vehicle Analysis

The dashboard analyzes different vehicle types, including:

* Auto
* Bike
* eBike
* Go Mini
* Go Sedan
* Premier Sedan
* Uber XL

### 5. Customer & Service Analysis

* Customer ratings
* Driver ratings
* Customer retention rate
* Service quality score
* Premium peak-hour index

### 6. Distance Analysis

Ride distance is analyzed using categories such as:

* Short (0–5 km)
* Medium (5–15 km)
* High (15–30 km)
* Extra Long (30+ km)

## 📈 Key Metrics

Some important metrics from the dashboard include:

* **Total Bookings:** 148.767K
* **Cancelled Rides:** 37.5K
* **Customer Retain Rate:** 30.24%
* **Sum of Revenue per KM:** 3.86M
* **Premium Peak Hour Index:** 72.53%
